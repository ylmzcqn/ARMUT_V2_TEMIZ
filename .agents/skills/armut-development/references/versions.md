# Version and recovery evidence

Use system_readiness, development_status and recovery_center to inspect source verification, recorded workflows and verified device images. Compare source hashes before reusing an older report. A source checkpoint is not a Git commit; an installed plugin is not a connected repository.

Use read_source/source_files for bounded source investigation and web_search/read_web_page for public documentation. No private GitHub API access, push, PR or commit tool is currently exposed to local Armut. State that limit rather than inventing remote history. Codex's GitHub connection cannot be transferred by copying browser tokens or configuration.

Deployment needs explicit target scope and existing permissions. Verify reboot identity, ELF and health before claiming firmware success. Recovery restores only verified artifacts to the selected device. Never stage or publish the entire untracked tree: private runtime data and secrets require explicit exclusion.
