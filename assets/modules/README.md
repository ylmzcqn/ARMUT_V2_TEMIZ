# Yerel modül SVG’leri

Bu proje için sıfırdan hazırlanmış vektör çizimleri. Dış görsel, uzaktan varlık veya kütüphane gerektirmez. Modül ailesinin görünümünü temsil eder; kullanıcının kartının üretici/revizyon fotoğrafı ve gerçek fiziksel pin sırası değildir. Uç adları ve kablo eşlemeleri SVG resimlerinin içine sabitlenmez; inventory.json kayıtlarından ayrı çizilir.

Dosyalar: display (ST7789 tipi ekran), imu (GY-521), proximity (FC-51), microphone (INMP441), amplifier (MAX98357 modülü), speaker, servo (SG90), radar, camera ve board (ESP32-S3 tipi kart).
